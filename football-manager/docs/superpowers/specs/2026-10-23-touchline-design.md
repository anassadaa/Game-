# Touchline — Club Architect design

An original, mobile-first football management game for long-running solo play. The player chooses a fictional club and steers it through repeatable 18-week seasons in a two-division, 10-club-per-division world. Every week offers a fixture and at least one consequential choice. A 15-minute-step match simulation supports tactical changes during play. The simulation is seeded, transparent enough to learn, and varied enough that budget, board pressure, squad development, rivals and injuries create changing priorities.

The dashboard surfaces the next fixture, league position, finances, trust and an actionable story. Squad management includes a starting eleven, formation, mentality, pressing, tempo, player fitness and morale. Recruitment includes scouted candidates, signings, sales and upgrades to the academy/scouting network. Training is one weekly focus with measurable trade-offs. Inbox events have two choices and affect club or squad state. Matches produce a readable timeline; league rivals play their own matches. Seasons reset fixtures and tables while retaining the club, developed players, money and records; promotion and relegation change the level of opponents and rewards. A new academy intake renews the pool, replenishes retirement-heavy squads to at least 14 players and preserves one starting goalkeeper.

Core rules live in a pure TypeScript engine. React renders the mobile UI and invokes engine transitions. State is saved locally with an explicit version, guarded loading, export and import. No account, network API, licensed teams, real player data, gambling, in-app purchase or multiplayer. Visual identity is editorial sports journalism: dark ink, warm cream, lime highlights, an illustrated tactical pitch and high-contrast numbers. This is a decision-driven match simulation, not a 3D football game. Responsive desktop layout and touch targets support Realme GT Neo 3T.

Core validation: repeatable seeded outcomes, bounded finances and stats, legal lineup, affordability checks, match completion, season turnover and robust save loading. The game is playable from a fresh clone using `npm ci`, `npm test`, and `npm run build`.
