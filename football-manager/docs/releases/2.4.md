# Touchline 2.4 — finance corrections

Android version 2.4, build 15. Package: `com.anassadaa.touchline`.

- Loans, equity funding and takeovers are recorded separately from earned income. Principal repayments and dividends are separate from operating costs.
- Share issues dilute all existing holders. Ownership totals cannot exceed 100%; cap-table changes cancel pending investor offers and acceptance checks ownership again.
- Investors receive profit-based season-end distributions under the selected policy; the old unconditional weekly charge is removed.
- Changing clubs preserves personal cash. Shares and loans are archived against the original club and restored if the player returns. Previous clubs' investments are visible under My finances. An owner accepting a job joins as a director; a job offer does not purchase the destination club.
- Wallet imports validate salary, ownership, investor mood and nested history. A malformed financial save is rejected rather than resetting the player's cash.
- Season-end salary reviews retain the completed season's transfer profit.

Valid v2.3 saves remain supported. Already recorded v2.3 transactions cannot be reconstructed retroactively; new financing uses the corrected categories.

## Android update

Build with JDK 21, Android SDK 35, and the original Touchline signing key:

```sh
npm ci
npm test
npm run build:apk
```

Signing reads `TOUCHLINE_KEYSTORE_PROPS` (or the original `/workspace/touchline-keystore/keystore.properties`). Without the original key the build is unsigned and cannot be installed as an update. Do not replace the signing identity or uninstall an existing game without exporting its save.

For this web-only fix, `scripts/package-apk-update.py` can also package `dist/` into the SHA256-pinned v2.3 native shell without an Android SDK. It strips the previous signatures and writes an explicitly unsigned 2.4/build15 APK. Native changes require the normal Gradle build.
